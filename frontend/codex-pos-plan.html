قبل أي تعديل:

6. بعد كل مرحلة شغّل الفحوص المناسبة وسجّل النتيجة.

الحالة المنجزة:
- تسجيل الدخول مربوط مع Laravel Sanctum.
- المنتجات والمخزون والعملاء والموردون والمبيعات والمشتريات والفواتير والمرتجعات والمستخدمون والأدوار والتقارير موجودة.
- التصنيفات متعددة المستويات مدعومة مع الإنشاء والتعديل والنقل والحذف ومنع النقل غير الصحيح.
- Pagination موجود في القوائم مع اختيار حجم الصفحة.
- منتجات POS تدعم التحميل التدريجي.
- تم اختبار بيع ومرتجع وRefund ودفعة عميل.
- تم إصلاح مشكلة Laravel مرتبطة بتاريخ اختياري.
- التقارير تعمل مع بيانات مبيعات فعلية.
- تصدير Excel-compatible للقوائم.
- تصدير التقارير ولوحة التحكم كصور PNG.

الخطوة 4: الدفعات والمشتريات
1. افحص جميع endpoints الخاصة بدفعات العملاء والموردين.
2. أضف سجل دفعات المورد: التاريخ، المبلغ، طريقة الدفع، المرجع، الملاحظات، والرصيد إن كان متاحًا.
3. تأكد من عرض سجل دفعات العميل.
4. اختبر دورة المشتريات: إنشاء الطلب، إرساله، الاستلام الجزئي والكامل، تحديث المخزون، تحديث رصيد المورد، وتسجيل الدفعة.
5. اختبر على بيانات Demo حقيقية، واحذف البيانات المؤقتة غير المطلوبة.

الخطوة 5: الرسائل وتجربة الاستخدام
1. أضف رسائل نجاح وفشل واضحة بالعربية لكل حفظ وتعديل وحذف وبيع ومرتجع ودفع.
2. امنع الضغط المكرر أثناء العمليات.
3. أضف loading وempty وerror states.
4. راجع RTL، الشاشات الصغيرة، الجداول العريضة، الأزرار، وPagination.
5. لا تغيّر الهوية البصرية عشوائيًا ولا تستبدل ngx-admin/Nebular بالكامل.

الخطوة 6: الجاهزية للإنتاج
1. افحص environment.ts وenvironment.prod.ts وAPI URL.
2. افحص CORS وSanctum.
3. افحص migrations وseeders وبيانات Demo.
4. تأكد أن التطبيق لا يعتمد على IDs ثابتة.
5. افحص انتهاء الجلسة و401 والصلاحيات والguards.
6. شغّل:
   npm run build
   npm run build:prod
   php artisan test
7. لا تعدّل الاختبارات فقط لجعلها تمر.

اختبارات التكامل المطلوبة:
1. تسجيل الدخول ولوحة التحكم.
2. تقرير ضمن فترة تحتوي مبيعات.
3. فتح أو استخدام شفت مفتوح.
4. بيع منتج stock ومنتج عليه ضريبة.
5. التحقق من المخزون بعد البيع.
6. بيع آجل إن كان مدعومًا.
7. دفعة عميل.
8. مرتجع وRefund.
9. إنشاء مورد وطلب شراء وإرساله.
10. استلام جزئي وكامل والتحقق من المخزون.
11. دفعة مورد والتحقق من الرصيد.
12. Pagination وتغيير per-page.
13. تصدير Excel لكل القوائم.
14. تصدير التقرير كصورة.
15. اختبار الصلاحيات بحساب محدود إن أمكن.
16. Angular problems/build وLaravel tests.

قواعد مهمة:
- لا تستخدم بيانات وهمية بدل API الحقيقي.
- لا تحذف تغييرات موجودة مسبقًا.
- لا تستخدم any أو casts غير ضرورية.
- لا تضف broad catch أو silent fallback.
- لا تعتبر وجود الزر كافيًا؛ اختبر الميزة فعليًا.
- إذا كان endpoint غير موجود، أضفه بطريقة متوافقة مع بنية Laravel.
- استخدم apply_patch للتعديلات اليدوية.
- افحص المشاكل بعد كل مجموعة تعديلات.

3. العمليات المنفذة فعليًا.
4. نتائج Laravel tests.
5. نتيجة Angular build.
6. المشاكل المتبقية.
7. الخطوة التالية المقترحة.
